# آریاتک — Ariatech

سایت شرکتی آریاتک. راهکارهای دیجیتال هوشمند.

## ساختار

این سایت **تک‌فایلی** است — کل سایت داخل `index.html` قرار دارد و هیچ build step یا وابستگی ندارد.

| فایل | توضیح |
|------|-------|
| `index.html` | کل سایت (HTML + CSS + JS inline) |
| `assets/img/` | ۱۸ تصویر (عکس‌های واقعی + لوگوی لیان دیزاین)، مجموع ۹۹۰KB |
| `fonts/` | فونت وزیرمتن (variable,wght 300-900) — محلی، بدون CDN |
| `serve.js` | سرور توسعه، فقط Node built-in (بدون dependency) |
| `package.json` | فقط اسکریپت — نیازی به `npm install` نیست |
| `logo.png` | لوگوی اصلی پروژه |

### تصاویر

| فایل | استفاده |
|------|---------|
| `lian-logo.png` | لوگوی هدر، فوتر و favicon |
| `hero.jpg` | تصویر هیرو |
| `work-1.jpg` … `work-9.jpg` | کاور ۹ نمونه‌کار |
| `about.jpg` | تصویر بخش درباره ما |
| `team-1.jpg` … `team-4.jpg` | عکس اعضای تیم |
| `cta.jpg` | پس‌زمینه بخش CTA |

> **تعویض با عکس واقعی:** فایل‌ها را با همان نام و نسبت ابعاد جایگزین کن — نیازی به تغییر کد نیست.
> برای لوگو، نسخه با **پس‌زمینه شفاف** (PNG) بگذار؛ نسخه فعلی از فایل اصلی لیان دیزاین
> پس‌زمینه مشکی داشت که شفاف شد.

> **چرا فونت محلی است؟** `fonts.googleapis.com` روی بعضی شبکه‌ها کند یا مسدود است و چون
> `<link>` رندر را بلاک می‌کند، صفحه سفید می‌ماند. با فونت محلی سایت بدون هیچ درخواست
> خارجی بالا می‌آید و حتی آفلاین هم کار می‌کند.

## اجرا

**بدون نصب هیچ چیز:**

```bash
npm run dev
```

سپس <http://localhost:3000>

> این پروژه **هیچ dependency ندارد**، پس `npm install` لازم نیست. فقط Node (نسخه ۱۸ به بالا) کافی است.

روش جایگزین — فایل `index.html` را مستقیم در مرورگر باز کنید.
